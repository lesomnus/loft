# 라벨

라벨의 코드가 무엇이고 어느 주소로 인쇄되는지입니다. 빈 라벨을 인쇄하는 곳은 설정 › 라벨이고, 자산의 라벨은 그 자산의 화면에서 인쇄합니다.

- 라벨 QR은 이 배포의 서비스 주소로 인쇄됩니다: `<public_url>/l/<코드>`(D28, D82). 그래서 휴대폰 기본 카메라로 찍어도 바로 그 자산이 열립니다.
- `/l/<코드>`는 서비스 주소의 스캔 화면(`/scan/<코드>`)으로 넘기기만 합니다. 코드가 어느 워크스페이스의 것인지는 보지 않습니다.
- 라벨 코드는 Crockford base32 8자(`7K3M-Q9TX` 처럼 넷씩 끊어 라벨 아래에도 인쇄)이고 서비스 전체에서 하나뿐입니다. 소문자나 `-` 없이 써도, `I`·`L` 을 `1` 로, `O` 를 `0` 으로 읽습니다.
- 스캔은 지금 연 워크스페이스에서 코드를 풉니다(`LabelService.Resolve`, `loft scan`). 다른 워크스페이스의 라벨은 없는 라벨과 똑같이 "찾지 못함"입니다. 라벨이 어느 워크스페이스에 있는지 찾던 것(`LabelService.Locate`)은 걷어냈습니다(D84).
- 라벨은 `LabelService` 의 `Print`(빈 라벨 또는 자산의 라벨), `Bind`, `Unbind`(`void` 면 폐기), `Resolve` 입니다.
- 휴대폰의 카메라는 HTTPS에서만 열립니다([휴대폰으로 써 보려면](running.md#휴대폰으로-써-보려면)).
- 워크스페이스마다 자기 도메인을 두던 것은 걷어냈습니다(D82). 포털에서 다시 설계합니다(loft#326).
